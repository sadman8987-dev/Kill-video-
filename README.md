# 🎬 Telegram Media Downloader Bot

بوت تيليجرام لتحميل الفيديو والصوت من يوتيوب وتيك توك وإنستغرام وفيسبوك وX وأكثر من 1000 موقع، مبني باستخدام aiogram 3 وyt-dlp وffmpeg وSQLite.

## المميزات
- تنزيل الفيديو بجودات متعددة أو استخراج الصوت MP3.
- البحث بالاسم وقوائم التشغيل.
- كاش للملفات وتقسيم الملفات الكبيرة.
- متابعة تقدم التنزيل وإمكانية الإلغاء.
- إعدادات عربية وإنجليزية لكل مستخدم.
- حدود يومية ومكافحة الإغراق واشتراك إجباري.
- لوحة إدارة وإحصائيات.
- Polling أو Webhook مع Docker.

## التشغيل
يتطلب Python 3.11+ وffmpeg وdeno، أو Docker.
انسخ `.env.example` إلى `.env` وأضف `BOT_TOKEN` و`ADMIN_IDS`.

## Railway
انشر باستخدام Dockerfile، وأضف متغيرات البيئة المطلوبة. استخدم Volume على `/app/data` لحفظ قاعدة SQLite.

استخدم البوت فقط لتنزيل المحتوى الذي تملكه أو لديك إذن بتنزيله.
